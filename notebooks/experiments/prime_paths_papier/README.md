# Efficient Prime Paths Generation — Experiments

This folder contains the experimental materials associated with the publication **“Efficient Prime Paths Generation.”**

## Contents

* Scripts used to run the experiments
* Result outputs
* Supporting utilities for reproducing the evaluation

## Dataset

The dataset used in the experiments is available at the following link:
**https://zenodo.org/records/17569752**

## Reproducibility

To reproduce the experiments, download the dataset from the link above and place it in the appropriate directory expected by the scripts. Then run the experiment scripts according to your environment and configuration.

## Notes

These materials are provided to support transparency and reproducibility of the results reported in the paper.
